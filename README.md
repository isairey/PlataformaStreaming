# 🌌 Acerca del proyecto

**Flix TV Clone** es una plataforma multimedia inspirada en servicios OTT modernos como Netflix y otras aplicaciones de streaming.

El proyecto fue desarrollado completamente con tecnologías frontend puras y un servidor Node.js ligero para simular una experiencia multimedia profesional.

La aplicación permite:

- 🎬 Explorar películas y series
- 📺 Catálogo multimedia
- 👤 Sistema de perfil de usuario
- 📡 Simulación de Live TV
- 💳 Planes de suscripción
- 📱 Diseño responsive

## 📋 Requisitos del sistema

- NPM

---

# 🚀 Cómo ejecutar el proyecto

## 🖱️ Método 1 — Script automático (Recomendado)

Ejecutar:

```bash
start.bat
```

o desde terminal:

```bash
.\start.bat
```

---

## ⚙️ Método 2 — Instalación manual

### 1️⃣ Instalar dependencias

```bash
npm install
```

---

### 2️⃣ Ejecutar servidor

## Opción A — Servidor Node.js

```bash
npm start
```

o

```bash
node server.js
```

---

## Opción B — HTTP Server

```bash
npm run serve
```

# 🐛 Solución de problemas

## ❌ Node.js no encontrado

- Instalar Node.js
- Reiniciar terminal
- Verificar:

```bash
node --version
```

---

## ⚠️ Puerto 3000 en uso

Cambiar puerto en:

```js
const port = 3001;
```

---

## ⚡ CSS/JS no cargan

- Revisar rutas
- Verificar consola del navegador
- Confirmar estructura de archivos
